# Profile Card Generator 🪪

This is a simple **Profile Card Generator** project made using **HTML, CSS and JavaScript**.  
In this project, the user enters their details in a form and clicks the **Submit** button.  
After submitting, a **profile card** is automatically generated and displayed on the screen.

---

##  Features
- User-friendly form UI
- Generates a profile card on submit
- Displays user details inside the card
- Clean and responsive design
- Simple JavaScript DOM manipulation
